# Contributing / 参与维护

Thank you for helping improve Silver Studio. Open an issue to report a bug or discuss a larger change, or fork the repository and open a pull request for a focused improvement.

欢迎一起维护：问题与建议请开 Issue；改进代码或文档可 Fork 仓库后提交 Pull Request。较大的设计调整请先讨论。

Before submitting / 提交前：

- Run `node --check plugin.js` and `npm test`; no dependency installation is needed.
- For visual changes, include light/dark screenshots with fictional content and report your OS and Hermes Desktop version. Do not upload private chats or credentials.
- Keep styles scoped to this theme and preserve cleanup when it is disabled. Avoid changing chat behavior or layout controls.
- Describe what changed and how you tested it. Maintainers review and merge accepted pull requests.

代码检查使用 `node --check plugin.js` 与 `npm test`。外观改动请附明暗效果、系统及 Hermes 版本；截图使用虚构内容。样式只作用于本主题，保留禁用清理逻辑，不改变聊天行为或布局开关。请说明改动及验证方式。

Contributions are accepted under the project's MIT license. / 贡献按本项目 MIT 许可证发布。
