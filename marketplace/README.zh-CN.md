# Silver Studio · 银境 — Hermes 配色主题

[English](https://github.com/wukangcheng1994/hermes-desktop-theme-silver/blob/main/marketplace/README.md) | 简体中文

纯白画布、浅银色表面、石墨文字和蓝色重点色。包含 **Silver Studio Light** 浅色版和 **Silver Studio Dark** 深色版。

## 在 Hermes Desktop 使用

在 Hermes 的主题市场中搜索 **Silver Studio** 或 **hermes-silver-studio**，安装后选择配色。只有扩展在 VS Code Marketplace 发布并被索引后才能搜到；较旧的 Hermes 版本可能没有主题市场搜索。

本包**仅提供配色**。Hermes 读取主题 JSON，不运行扩展代码。[完整版 Hermes 桌面插件](https://github.com/wukangcheng1994/hermes-desktop-theme-silver)中的玻璃效果、气泡位置和滚动布局调整不包含在内。Hermes 可能为保证对比度调整部分颜色。

## 在 VS Code 使用

安装扩展，打开 **首选项：颜色主题**，选择 **Silver Studio Light** 或 **Silver Studio Dark**。包含代码语法配色，没有可执行扩展代码、遥测或依赖。
