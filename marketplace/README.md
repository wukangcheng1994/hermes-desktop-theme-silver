# Silver Studio — Hermes Theme

English | [简体中文](https://github.com/wukangcheng1994/hermes-desktop-theme-silver/blob/main/marketplace/README.zh-CN.md)

Clear white, pale silver surfaces, graphite text, and blue accents. Includes **Silver Studio Light** and **Silver Studio Dark**.

## Hermes Desktop

In Hermes's theme marketplace search, look for **Silver Studio** or **hermes-silver-studio**, then install and select a color theme. Availability requires the extension to be published and indexed in the VS Code Marketplace; older Hermes versions may not include marketplace search.

This package supplies **colors only**. Hermes imports the contributed theme JSON; it does not run extension code. Glass effects, bubble placement, and scrolling/layout changes from the [full Hermes desktop plugin](https://github.com/wukangcheng1994/hermes-desktop-theme-silver) are not included. Hermes may adapt colors for contrast.

## VS Code

Install the extension, open **Preferences: Color Theme**, and select **Silver Studio Light** or **Silver Studio Dark**. Syntax colors are included. No executable extension code, telemetry, or dependencies.
